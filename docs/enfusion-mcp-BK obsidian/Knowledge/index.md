# enfusion-mcp-BK Knowledge Library

This library holds internal decisions, reusable lessons, and unresolved discussions for enfusion-mcp-BK. It is separate from developer documentation and canonical release history.

## Areas

- [[Knowledge/Decisions/index|Decisions]] - choices that need maintainer confirmation and a revisit trigger. The GitHub tracker's append-only decision comments remain authoritative; notes here are transcriptions.
- [[Knowledge/Lessons/index|Lessons]] - evidence-backed successes, failures, limitations, and reusable rules (e.g. probe and prototype results).
- [[Knowledge/Discussions/index|Discussions]] - open questions and proposals that are not authoritative.

## Lifecycle

New notes start as draft. A decision transcription moves to review until a maintainer confirms it matches the tracker's decision record. A discussion must not be cited as a decision. Lessons retain their evidence and limitations.

All notes remain internal unless governance metadata explicitly authorizes an export. No note contains secrets or private operational data.
